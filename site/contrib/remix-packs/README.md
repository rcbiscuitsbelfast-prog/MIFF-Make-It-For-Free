# Remix Starter Packs

Use these packs to quickly remix a zone with orchestration-first design and remix-safe assets.

Packs:
- `grove3d/` — Grove 3D starter (map JSON + tile subset)
- `toppler_medieval/` — Toppler Medieval starter (orchestration + UI notes)
- `spirit_tamer/` — Spirit Tamer starter (dialogue tree + orchestration)
