About This Tutorial

This is a complete implementation of a simple 2D platformer game using the MIFF Framework. It demonstrates:

  • Game state management
  • Entity systems (Player, Items, Physics)
  • Event-driven architecture
  • Input handling
  • Collision detection
  • Score and level progression

The source code is available in the src/ directory and can be used as a starting point for your own MIFF Framework games.
