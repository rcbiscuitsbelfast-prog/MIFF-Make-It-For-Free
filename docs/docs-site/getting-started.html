🚀 Getting Started with MIFF

Your first steps into the Modular Interactive Framework for the Future

Quick Start

MIFF is designed to be immediately usable. Here's how to get started:

1. Explore the Sampler

Start by exploring the MIFF Sampler to see what's possible with the framework.

2. Try the Studio

Use MIFF Studio to build your first scene and experiment with modules.

3. Check RenderWorld

Experience the RenderWorld Hub for AI-native game previews.

Core Concepts

  • Modules: 157+ pure JavaScript modules for game development
  • Cross-Platform: Deploy to web, mobile, and desktop
  • AI-Native: Built-in AI tools for development
  • Modular: Use only what you need
