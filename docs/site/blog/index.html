Tutorial Getting Started Guide

Getting Started with MIFF: Your First Game in 10 Minutes

Learn how to create your first game using MIFF in just 10 minutes. This comprehensive tutorial covers everything from installation to deployment.

Step 1: Installation

Getting started with MIFF is simple:

npm install @miff/framework
npx miff init my-first-game
cd my-first-game

Step 2: Basic Setup

Create your first scene with just a few lines of code:

import { SceneBuilder, PlayerController } from '@miff/framework';

const scene = new SceneBuilder()
  .addEntity('player', { x: 100, y: 100 })
  .addSystem(new PlayerController())
  .build();

Step 3: Adding Gameplay

Enhance your game with MIFF's modular systems:

  • Physics simulation with PhysicsSystemPure
  • Audio integration with AudioBridgePure
  • AI behaviors with BattleAIPure
  • Network multiplayer with NetworkBridgePure

Step 4: Export & Deploy

Deploy to any platform with one command:

npx miff export --target web
npx miff export --target unity
npx miff export --target godot
